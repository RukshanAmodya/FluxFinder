# 🌌 FluxFinder: The AI-Powered Metal & EMF OS

![FluxFinder Banner](assets/images/banner.png)

## 🚀 Overview
**FluxFinder** is a high-end, futuristic Android application designed for 2026. It leverages advanced on-device sensor fusion and Edge AI to detect magnetic fields and electromagnetic frequencies with surgical precision. 

Replacing traditional needles with an **Antigravity Fluid Engine**, FluxFinder transforms raw data into a living, reactive experience.

---

## ✨ Key Features

### 💧 Antigravity Liquid UI
- **Reactive Mercury Droplet**: A 3D-styled liquid metal center that pulls and stretches toward the strongest magnetic field.
- **Dynamic Physics**: Organic fluid motion based on real-time magnetometer X-Y-Z axes.

### 🧠 AI Material Discrimination
- **Signal Analysis**: Classifies magnetic spikes into **Ferrous Metal (Iron)**, **Live Wires (AC)**, or **Electronic Interference**.
- **Edge AI**: Local heuristic processing for instantaneous detection.

### 🗺️ 3D Magnetic Mapping
- **LiDAR-style Scan**: Real-time 3D point-cloud visualization that plots magnetic peaks in your space.
- **Spatial Memory**: Tracks recent history to create a magnetic signature of your environment.

### 👻 Ghost/EMF Hunting Mode
- **Thermal Purple Theme**: Increased sensitivity and high-frequency tracking for micro-fluctuations.
- **Smart Flashlight**: Automatically triggers the device flash when high EMF levels are detected in low light.

### 🎮 Gamification
- **Progression System**: Level up from a **Rookie Finder** to a **Master Archaeologist**.
- **Haptic 2.0**: Heartbeat vibration patterns that intensify as you approach your target.

## 📦 Getting Started

### Prerequisites
- Flutter SDK (Latest Stable)
- Android Studio / VS Code
- A physical Android device (Magnetometer is required)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/RukshanAmodya/FluxFinder.git
   ```
2. Navigate to the project:
   ```bash
   cd flux_finder
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```
